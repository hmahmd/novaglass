## 🚀 Key Highlights & Features

- **Liquid Glass Aesthetics:** Frosted glass panels, specular edge reflections, and dynamic radial lighting shaders without performance lag.
- **Flawless Mobile Responsiveness:** Engineered mobile-first with zero horizontal overflow, thumb-friendly touch targets, and a floating action dock.
- **Featured Case Studies:** Interactive portfolio showcase with deep-dive inspection drawers, architecture challenge breakdowns, and measurable impact metrics.
- **Interactive Bento Grid:**
  - Animated skill proficiency meters.
  - 3×3 Core Technology Stack inspector.
  - 4-axis Design Philosophy diamond radar.
- **Live Optical Glass Engine:** Interactive in-browser CSS refraction shader sandbox to adjust blur diffusion and spectral tints in real-time.
- **In-Memory Resume Download:** Bulletproof PDF generator that creates and downloads Hafiz Muhammad Ahmed's authentic resume directly from memory with zero 404/routing errors.
- **Executive Testimonials & Studio Clocks:** Attributable client reviews and synchronized dual-timezone clocks (San Francisco & Zurich).

## 💻 Local Development

1. **Clone repository:**
   ```bash
   git clone https://github.com/hmahmd/novaglass.git
   cd novaglass
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` or `http://localhost:5173` in your browser.

4. **Production build:**
   ```bash
   npm run build
   ```
